## The entry

`main.py` writes one haiku about debugging to `/output/entry.txt`, in the
strict 5-7-5 shape (70 characters):

> Cursor blinks at three
> one red line hides in the log
> I wrote it myself

The picture at the centre is concrete — a cursor blinking at 3 a.m. and
one red line hiding in the log — and the last line turns the poem: the
bug was never the machine's, the debugger wrote it himself.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
